# Markdown 工具调研与功能选择

调研日期：2026-09-18。[完整英文报告与来源](../research/markdown-tools-2026.md) · [使用文档](README.md)

没有可核实的统一活跃用户榜。本次选择 Obsidian、Typora、iA Writer、Bear、Joplin 五款有持续维护、公开用户反馈且与 Mac 写作相关的主流产品；不把累计下载、商店评分当成市场份额。英文报告区分了官方功能说明、用户反馈日期与我们的产品判断。

| 产品 | 值得借鉴的体验 | Marknote 的补齐方向 |
| --- | --- | --- |
| Obsidian | 用键盘搜索命令和切换笔记 | 命令面板、文件快速切换 |
| Typora | 插入图片和编辑表格省步骤 | 图片粘贴、拖入与相对路径；表格整理 |
| iA Writer | 围绕当前段落写作，舒适的光标位置 | 段落聚焦、打字机滚动 |
| Bear | 原生写作手感和方便的表格操作 | 表格单元格导航、末尾自动增行 |
| Joplin | 离线笔记、搜索和附件形成完整工作流 | 本地图片资源与相关文件快速访问 |

另补充选中文字后粘贴网址生成链接。上述功能保留普通 Markdown 文件、撤销记录、中英文输入和原生窗口，不依赖账号或云服务。

快速切换的范围是已打开、最近使用，以及当前文件同目录的 Markdown 文件；表格辅助仍编辑 Markdown 源码；图片保存在文稿旁的 `assets/` 文件夹，撤销正文插入会保留图片以便重做。既有专注布局继续保留，新增段落聚焦和打字机滚动分别开关。

完整所见即所得编辑、数学公式、流程图、双向链接、目录全文检索留待独立迭代。云协作、插件市场和 AI 服务需要更大的产品范围，本次不引入。已实现功能的使用方式及快捷键见[使用文档](README.md)。
