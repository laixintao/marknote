# 留一点空间，给思考。

欢迎来到 **墨笺**。一个安静、轻盈的 Markdown 写作空间。

在左侧落笔，在右侧看见文字的样子。从一条灵感、一页笔记，或者一个新的故事开始。

> 写作，是让模糊的想法慢慢清晰。

## 从这里开始

- 用 **Markdown** 专注于内容
- 用左侧大纲，快速找到每个章节
- 用 **编辑** 和 **预览** 开关，选择单栏或双栏显示
- 按 `⌘ S`，将这页文字保存在你的 Mac 上

## 把想法变成文字

无需离开键盘，就能整理思路。

| 你想做的事 | 快捷键 |
| :--- | :--- |
| 加粗选中文字 | ⌘ B |
| 为文字添加链接 | ⌘ K |
| 在文稿中查找 | ⌘ F |
| 切换专注模式 | ⌘ ⇧ F |
